# MIS Employee Performance Dashboard

## Project Overview
An Excel-based MIS Dashboard built using:
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- XLOOKUP
- Data Validation
- KPI Cards

## Dashboard KPIs
- Total Employees
- Total Target
- Total Achieved
- Achievement %
- Total Salary
- Top Performer
- Lowest Performer

## Visualizations
- Department-wise Achievement
- Employee Count by Region
- Achievement Trend
- Top 5 Performers
- Bottom 5 Performers
- Data Quality Check

## Tools Used
- Microsoft Excel 2021
